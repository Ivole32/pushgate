Add to Home Screen first

On iPhone and iPad, web push notifications only work for web apps opened from the Home Screen (iOS/iPadOS 16.4 or later).

  1. Tap the Share button in Safari.
  2. Choose Add to Home Screen, then Add.
  3. Open Pushgate from the Home Screen icon and sign in there.

Set up with enrollment token

Create a one-time token on the server host:

docker compose exec pushgate /nodejs/bin/node src/cli.js enroll-token

Paste the one-time token you received to create the passkey for your account.
